[Swarms Marketplace](https://swarms.world) के लिए आधिकारिक कमांड-लाइन इंटरफ़ेस। एजेंट, प्रॉम्प्ट और टोकन प्रकाशित करें, कैटलॉग ब्राउज़ करें, और अपने टोकनाइज़्ड उत्पादों से क्रिएटर शुल्क एकत्र करें — पूरी तरह से अपने टर्मिनल से, स्क्रिप्टिंग, CI/CD और हेडलेस वातावरण के लिए प्रथम-श्रेणी समर्थन के साथ।

## अवलोकन

`swarms` Swarms Marketplace HTTP API के ऊपर एक पूर्णतः स्क्रिप्ट-योग्य क्लाइंट है। यह सीधे उन कार्यों पर मैप होता है जो एक मार्केटप्लेस व्यवसाय को चलाते हैं:

- **बड़े पैमाने पर उत्पाद प्रकाशित करें।** एक ही कमांड, एक JSON मैनिफ़ेस्ट, या CI में मैनिफ़ेस्ट डायरेक्टरी से एजेंट, प्रॉम्प्ट और टूल मार्केटप्लेस पर पुश करें। ब्राउज़र की ज़रूरत नहीं, मैन्युअल फ़ॉर्म की ज़रूरत नहीं।
- **ऑन-चेन टोकन लॉन्च करें।** एक कॉल में एजेंट को टोकनाइज़ करें — टिकर, क्वोट करेंसी, छवि और शुल्क मोड सहित। लॉन्च लेनदेन रनटाइम पर दिए गए वॉलेट कुंजी से साइन किया जाता है।
- **एकल या बल्क में क्रिएटर शुल्क एकत्र करें।** एक टोकन पर, अपने हर टोकन पर, या मार्केटप्लेस के प्रत्येक टोकनाइज़्ड mint पर एक ही बैच में दावा करें — "विफलता पर जारी रखें" शब्दार्थ के साथ।
- **अपने कैटलॉग का ऑडिट करें।** अपने प्रकाशित उत्पादों को एक संरचित ट्री के रूप में रेंडर करें, केवल टोकनाइज़्ड के लिए फ़िल्टर करें, और डाउनस्ट्रीम डैशबोर्ड के लिए JSON निकालें।
- **मार्केटप्लेस की खोज करें।** हर टोकनाइज़्ड उत्पाद को पेज द्वारा देखें (कोई API key आवश्यक नहीं) — फ़्लैट सूची या JSON के रूप में, जो इंडेक्सिंग, मिररिंग या एनालिटिक्स के लिए उपयुक्त है।
- **सब कुछ स्वचालित करें।** जब सही environment वैरिएबल सेट होते हैं तो हर कमांड ग़ैर-इंटरैक्टिव है, मानक एग्ज़िट कोड लौटाता है, और TTY के बाहर या `$CI` के तहत चलने पर एनिमेशन / प्रॉम्प्ट निष्क्रिय कर देता है।

### क्षमताएँ एक नज़र में

| क्षमता                            | कमांड                                            | प्रमाणीकरण आवश्यक       |
| --------------------------------- | ------------------------------------------------ | ----------------------- |
| API keys पेज खोलें                | `swarms api-key`                                 | कोई नहीं                |
| environment प्रमाणीकरण सत्यापित करें | `swarms login` · `swarms whoami`             | API key                 |
| एजेंट प्रकाशित करें               | `swarms launch agent`                            | API key                 |
| प्रॉम्प्ट प्रकाशित करें           | `swarms launch prompt`                           | API key                 |
| एजेंट के लिए ऑन-चेन टोकन लॉन्च करें | `swarms launch token`                          | API key + वॉलेट कुंजी   |
| अपने प्रकाशित उत्पादों की सूची    | `swarms list`                                    | API key                 |
| हर टोकनाइज़्ड उत्पाद ब्राउज़ करें | `swarms list-tokenized` (उपनाम `swarms tokens`)  | कोई नहीं                |
| उत्पाद का लिस्टिंग पेज खोलें      | `swarms open <id\|ca>`                           | कोई नहीं                |
| एकल mint पर शुल्क दावा            | `swarms claim --ca <mint>`                       | वॉलेट कुंजी             |
| बैच में शुल्क दावा                | `swarms claim-all`                               | वॉलेट कुंजी             |
| किसी भी रीड कमांड के लिए JSON     | `--json` फ़्लैग                                   | parent कमांड के समान    |

## स्थापना

```bash
# ग्लोबल इंस्टॉल (दैनिक / शेल उपयोग के लिए अनुशंसित)
npm install -g swarms-market

# या बिना इंस्टॉल किए चलाएँ (CI के लिए सुविधाजनक)
npx swarms-market@latest --help

# CI में किसी विशिष्ट संस्करण को पिन करें
npm install -g swarms-market@0.1.0
```

इंस्टॉल के बाद सत्यापित करें:

```bash
swarms --version
swarms --help
```

> **ध्यान दें:** npm पर पैकेज का नाम `swarms-market` है, लेकिन यह जो बाइनरी इंस्टॉल करता है उसका नाम `swarms` है। यदि आपने पहले से Python वाला `swarms` पैकेज इंस्टॉल किया है (यह भी इसी नाम की बाइनरी देता है), तो दोनों आपके `PATH` पर एक-दूसरे को छिपा देंगे। `which swarms` चलाकर देखें कि कौन सा सक्रिय है; जिसकी ज़रूरत नहीं उसे अनइंस्टॉल करें, या इसे सीधे `npx swarms-market <command>` के माध्यम से चलाएँ।

### अनइंस्टॉल

```bash
npm uninstall -g swarms-market
```

## त्वरित प्रारंभ

```bash
# 1. API key प्राप्त करें (https://swarms.world/platform/api-keys खोलता है)
swarms api-key

# 2. इसे export करें
export SWARMS_API_KEY="sk-…"
export SWARMS_USERNAME="your-username"   # वैकल्पिक, लेकिन अधिकांश कमांड पर --user छोड़ देता है

# 3. प्रमाणीकरण सत्यापित करें
swarms login

# 4. मैनिफ़ेस्ट से अपना पहला एजेंट प्रकाशित करें
swarms launch agent \
  --name "Hello Agent" \
  --description "Says hi" \
  --code-file ./agent.py \
  --free

# 5. देखें कि आपने क्या प्रकाशित किया है
swarms list

# 6. मार्केटप्लेस ब्राउज़ करें
swarms list-tokenized
```

## प्रमाणीकरण

<https://swarms.world/platform/api-keys> पर key प्राप्त करें (या `swarms api-key` चलाएँ)। उस पेज से keys बनाई, नामित और रद्द की जा सकती हैं।

```bash
export SWARMS_API_KEY="sk-…"
swarms whoami      # पुष्टि करता है कि key लोड है; पहले/अंतिम 4 वर्ण प्रिंट करता है
```

केवल-पढ़ें कमांड जो आपके खाते को संशोधित नहीं करते (विशेष रूप से `list-tokenized` और `api-key` ओपनर) बिना API key के काम करते हैं। हर दूसरे कमांड के लिए यह आवश्यक है।

## कॉन्फ़िगरेशन

सभी कॉन्फ़िगरेशन environment-driven है। CLI कोई कॉन्फ़िग फ़ाइल नहीं पढ़ता या लिखता।

| वैरिएबल                       | उद्देश्य                                                                                     | डिफ़ॉल्ट              |
| ----------------------------- | -------------------------------------------------------------------------------------------- | --------------------- |
| `SWARMS_API_KEY`              | मार्केटप्लेस endpoints (publish, list, खाता-स्कोप्ड reads) के लिए Bearer टोकन।               | _प्रमाणीकरण हेतु आवश्यक_ |
| `SWARMS_USERNAME`             | `list` के लिए डिफ़ॉल्ट `--user`। `swarms list` को बिना फ़्लैग चलाने देता है।                  | _(--user पास करें)_   |
| `SWARMS_WALLET_PRIVATE_KEY`   | ऑन-चेन ऑपरेशनों के लिए वॉलेट प्राइवेट key (base58)। केवल मेमोरी में रखा जाता है।            | _(unset होने पर पूछता है)_ |
| `PRIVATE_KEY`                 | `SWARMS_WALLET_PRIVATE_KEY` का उपनाम, सामान्य `.env` परंपराओं के साथ संगतता के लिए।          | _(unset होने पर पूछता है)_ |
| `SWARMS_NO_ANIM`              | कोई भी मान सेट करें — इंटरैक्टिव टर्मिनल में भी welcome एनिमेशन निष्क्रिय कर देता है।          | _(TTY में एनिमेट)_    |
| `CI`                          | सेट होने पर welcome एनिमेशन स्वचालित रूप से बंद हो जाता है (प्रत्येक प्रमुख CI प्रदाता सेट करता है)। | _(पता लगाया जाता है)_ |
| `TERM=dumb`                   | यह भी एनिमेशन को निष्क्रिय करता है।                                                          | _(पता लगाया जाता है)_ |
| `NO_COLOR`                    | `chalk` द्वारा सम्मानित — ANSI रंगों को पूरी तरह से निष्क्रिय करने के लिए सेट करें।          | _(डिफ़ॉल्ट रूप से रंग ऑन)_ |

## कमांड संदर्भ

```
swarms api-key                अपने ब्राउज़र में API keys पेज खोलें
swarms login                  सत्यापित करें कि SWARMS_API_KEY सेट है
swarms whoami                 सक्रिय key (masked) और base URL दिखाएँ

swarms launch agent           एजेंट प्रकाशित करें
swarms launch prompt          प्रॉम्प्ट प्रकाशित करें
swarms launch token           चेन पर एजेंट को टोकनाइज़ करें

swarms list                   आपके प्रकाशित उत्पाद, लाल/सफ़ेद ट्री के रूप में
swarms list-tokenized         मार्केटप्लेस पर हर टोकनाइज़्ड उत्पाद
                              (उपनाम: swarms tokens)
swarms open <id|ca>           आपके ब्राउज़र में उत्पाद का लिस्टिंग पेज खोलें

swarms claim                  एक टोकनाइज़्ड उत्पाद के लिए शुल्क दावा (टोकन mint द्वारा)
swarms claim-all              कई उत्पादों पर शुल्क दावा
```

किसी भी समय फ़्लैगों की आधिकारिक सूची के लिए `swarms <command> --help` चलाएँ। उप-कमांड सहायता (`swarms launch --help`, `swarms list-tokenized --help` आदि) उसी रेंडरिंग का उपयोग करती है।

विस्तृत उप-कमांड दस्तावेज़ीकरण, मैनिफ़ेस्ट प्रारूपों और वर्कफ़्लो उदाहरणों के लिए [अंग्रेज़ी README](../README.md#command-reference) देखें।

## सुरक्षा मॉडल

CLI उन वातावरणों में उपयोग के लिए डिज़ाइन किया गया है जहाँ credentials को auditable और reproducible होना चाहिए।

**प्रमाणीकरण।**
API key केवल `$SWARMS_API_KEY` से पढ़ी जाती है और HTTPS पर `Authorization: Bearer <key>` के रूप में भेजी जाती है। CLI डिस्क पर कहीं भी API key नहीं लिखता, cache नहीं करता, या persist नहीं करता। Keys <https://swarms.world/platform/api-keys> पर प्रबंधित होती हैं और किसी भी समय revoke की जा सकती हैं।

**वॉलेट प्राइवेट key संभालना।**
`claim`, `claim-all` और `launch token` के लिए आवश्यक वॉलेट प्राइवेट key निम्नलिखित क्रम में स्रोत की जाती है: स्पष्ट `--private-key` फ़्लैग → `$SWARMS_WALLET_PRIVATE_KEY` → `$PRIVATE_KEY` → इंटरैक्टिव प्रॉम्प्ट (छिपा हुआ इनपुट, कोई echo नहीं, कोई history नहीं)। key एक कमांड की अवधि के लिए प्रोसेस मेमोरी में रखी जाती है और **कभी भी** डिस्क पर नहीं लिखी जाती, लॉग नहीं की जाती, या cache नहीं की जाती। CLI में कोई "मेरा वॉलेट याद रखें" मोड नहीं है।

**Transport।**
सभी requests `https://swarms.world` पर HTTPS का उपयोग करते हैं। होस्ट hardcoded है — कोई env override नहीं — इसलिए कोई आवारा shell वैरिएबल Bearer key या वॉलेट प्राइवेट key को किसी अन्य होस्ट पर redirect नहीं कर सकता। CLI किसी भी फ़्लैग के तहत TLS verification निष्क्रिय नहीं करता।

**टेलीमेट्री।**
CLI किसी भी प्रकार की टेलीमेट्री नहीं भेजता। यह केवल [Command reference](../README.md#command-reference) में सूचीबद्ध मार्केटप्लेस API endpoints पर network calls करता है, और केवल तब जब उन्हें आवश्यकता वाली कमांड invoke की जाती है।

## Exit कोड

| कोड | अर्थ                                                                          |
| ---- | ----------------------------------------------------------------------------- |
| 0    | सफलता                                                                         |
| 1    | कमांड त्रुटि — अमान्य इनपुट, validation विफलता, API non-2xx response          |
| 130  | SIGINT (Ctrl-C) द्वारा बाधित; बाहर निकलते समय कर्सर restore किया जाता है       |
